# 🏨 Hotel Management System

A fully functional **Hotel Management System** web application built using **HTML, CSS, and JavaScript**.

**Developed by: Nimitha BC**

---

## 📌 Features

- 🛏️ **Room Availability** — View all 12 rooms with live availability status
- 📅 **Room Booking** — Book rooms with guest details, dates, and auto price calculation
- 💰 **Price Summary** — Automatic total calculation based on room type and number of nights
- 📋 **My Bookings** — View, manage and cancel bookings
- 🔧 **Admin Dashboard** — Overview of all rooms, revenue, and checkout management
- 🔍 **Filter Rooms** — Filter by room type and availability
- 💾 **Data Persistence** — All data saved using localStorage
- 📱 **Responsive Design** — Works on mobile and desktop

## 🚀 How to Run

1. Download or clone this repository
2. Open `index.html` in any browser
3. No installation needed!
